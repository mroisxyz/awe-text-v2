A small, quiet text about a harbor light — an image that settles slowly and keeps growing after the last line. No instruction, only the water and the buoy and the tide, shown plainly so the calm comes from the words themselves.

## Run it

```
node main.ts
```

Runs on Node 22, standard library only. Writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (default `/output`) and logs a short line to stderr.
